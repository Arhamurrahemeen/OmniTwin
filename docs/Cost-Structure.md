# OmniTwin — Cost Structure

**Split out from Overview.md on 2026-08-14** to keep Overview focused on product. This file holds CAPEX/OPEX.

**Status:** Company is pre-revenue and pre-scale. Full CAPEX/OPEX model not yet built. Figures below are what currently exists — everything else marked open.

**Team:** four members, all currently uncompensated (see [Team.md](Team.md)) — Arham, Tasbiha, Asma, Abdul Basit.

---

## CAPEX

| Item | Amount |
|---|---|
| First hardware batch: 5 kits × ~10,000 PKR BOM (ESP32 1,100 PKR + vibration/temp/motor-driver/ultrasonic/IR sensors + 4-wheel chassis + moisture/humidity sensor) | ≈50,000 PKR |
| Dev cost to date (platform/dashboard build) | Not yet costed — built by the founding team, unpaid |

## OPEX (annual)

| Item | Amount |
|---|---|
| Hosting/infra | 25,000–30,000 PKR/yr |
| Team stipends | Deferred — not yet costed. Currently 4 founders working unpaid, so the current figure is PKR 0 and that is not a sustainable steady state |
| Support/maintenance | None budgeted — informal, team-handled for now |
| Marketing/GTM (campus visits, awareness sessions, community-building) | Not yet costed — qualitatively defined only |

**GTM cost driver:** Freemium is the primary marketing wedge — get engineering students aware of and comfortable with OmniTwin before selling into their university. Requires campus visits, in-person awareness sessions, community-building. This is a real, currently unbudgeted cost line, not a passive channel.

**Note on headcount cost:** the team grew from 3 to 4 in September 2026, which changes the stipends line and the support burden even though revenue has not started. Worth modelling before the DUET pilot rather than after.
